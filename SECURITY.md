# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| `0.1.x` | Yes |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities or credential leaks.

Instead, report security issues privately through GitHub's **Security Advisories** ("Report a vulnerability") on this repository, including:
- A description of the issue and affected component.
- Steps to reproduce without including real user credentials or session tokens.
